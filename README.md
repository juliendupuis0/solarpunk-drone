# Potager Solarpunk

Jeu Unity où un drone vu de dessus plante, arrose et récolte des légumes.

## Jouer

Jouable dans le navigateur : [Sur Itch.io](https://kingfishergaming.itch.io/potager-solarpunk)

## Ouvrir le projet

- Unity 6000.3.24f1 (6.3 LTS)
- Scène de départ : `Assets/Scenes/Intro`
- Scripts : `Assets/Scripts`
- Prefabs : `Assets/Prefabs`
- Contrôles (Input System) : `Assets/InputSystem_Actions.inputactions`

## Le jeu

Incarnez un drone au-dessus d'un champ.
Vous avez 3 objectifs :

- Planter
- Arroser
- Récolter

Une fois le score de 30 atteint la partie est terminée.

Tout ça en un temps record. Votre meilleur temps est conservé entre chaque partie.

Attention si vous mettez trop de temps à récolter alors la graine explose !

## Contrôles

### Clavier

- Se déplacer : flèches ou WASD
- Planter une graine : E
- Arroser (maintenir) : Q
- Pause : Échap

### Manette

- Se déplacer : stick gauche
- Planter : bouton Sud (A / ✕)
- Arroser (maintenir) : bouton Ouest (X / carré)
- Pause : Start
